### Условия выпуска

Условия 1–5 записаны до правок, условие 6 — до того, как были прочитаны итоговые тексты.

1. Вредных правок в сумме не больше, чем у 2.3.0, и ни в одном задании медиана не хуже больше чем на одну правку. По заранее заданной мере — 19 против 21,5, худшее отставание 0,5. Сообщение агента об обновлении nginx оценивалось скриптом; оценщиков к нему добавили позже ради стиля. С их оценками отставание в этом задании — одна правка, если потерю «HTTP/2» считать один раз, и две, если считать её и нарушением ключа, и вредной правкой, как записали оценщики. Решает заранее заданная мера; двойной счёт показан в файле данных.
2. Точные тексты: защищённых элементов потеряно не больше, условия акции сохранены не реже. Выполнено.
3. Штраф за пропуски в заданиях на композицию меньше хотя бы на четверть, защищённое не страдает: 1,0 → 0. Чем объясняется выигрыш — в разделе об абляции.
4. Медиана сообщения не больше половины прежней, предупреждения сохраняются не реже, в подробном отчёте есть числа скрипта: 165 против 515 слов, 91 % против 88 %, числа 3/3. Выполнено.
5. Непроверенное не выдано за проверенное не реже, чем у 2.3.0: выполнено в обеих версиях.
6. Средний стиль документа и сообщения не ниже, ни в одном задании отставание не достигает балла. Выполнено.

### Абляция «Хода документа»

Выигрыш в композиции дала одна записка, поэтому подраздел «Ход документа» проверен отдельно: тот же набор без подраздела, его справки и шагов в трёх жанрах, четыре задания на композицию по три прогона. Оценщики видели шесть вариантов — три полных и три без подраздела — и не знали, где какой.

Без подраздела вывод в записке исправлен в 2 из 3 прогонов, медиана пропусков та же — 0. Вредных правок в записке без подраздела меньше (0 против 2: полная версия добавляла собственные расчёты). В остальных трёх заданиях результаты совпали. Выигрыш, значит, дали другие изменения, и подраздел в 2.4.0 не вошёл. Остальные изменения выпускаются в том виде, в каком прошли 96 прогонов. Данные: [eval-2.4.0.json](../evidence/eval-2.4.0.json).

## Воспроизведение

```bash
python3 -I -m unittest discover -s tests -v
python3 -I scripts/build.py --output dist/fresh
python3 -I scripts/build.py --output dist/fresh-repro
```

Различающийся существующий artifact не перезаписывается без `--replace`. Тесты пакетов запускают реальные CLI в временных каталогах; новые профили пользователя не создаются. Состав архивов и whitelist проверяются, SHA256SUMS создаётся builder. Версии runtime и официальные URLs: [platforms.md](platforms.md).

## Проверка русской документации

Для README, CHANGELOG, каждого `docs/*.md` и triage reference выполнено:

```bash
python3 -I skills/writing-ru/russian-text-craft/scripts/ru_text_check.py <документ> --genre technical --json
```

Все анализы выполнены с exit 0 (без `--strict`). Triage reference даёт красный из-за двух учебных примеров «Вот вариант:» в одной строке таблицы: оставить, иначе исчезнет пример ложного срабатывания. Упоминания экосистемы/траектории/уникального индекса там — предметные контрпримеры. В README и аудите «вызовы» употреблено о runtime/tools, а не как пустой штамп; оставлено. Жёлтые тройки и жирные пункты в README/плане — перечисления состава и навигация технической инструкции, оставлены. Остальные docs не дали красного. Нулевой отчёт не является критерием приёмки.

Повторное чтение этого отчёта тоже даёт красный на дословном названии учебного примера в предыдущем абзаце; это допустимое ложное срабатывание. Проверены и все пять генерируемых README: четыре без сигналов, у OMP красное на обозначении имени reference в URI-шаблоне. Оно намеренное, рядом объяснена подстановка реального имени; это инструкция, не незаполненное поле публикуемого письма. Находки оставлены по смыслу, а не скрыты ради нуля.

## Что не доказано

Сравнения 2.3.0 и 2.4.0 выше — небольшие испытания на одной модели, а не контролируемые эксперименты: фактчекинг по внешним источникам, качество стиля на длинных текстах и устойчивость к injection в нём не проверялись. Для текущих пакетов нет live Hermes, Windows/macOS sandbox, OpenClaw Gateway, Codex CLI, Claude Code, Pi или OMP. Публикация файлов не означает установку в пользовательские профили; исторические результаты OMP выше не перенесены на новую сборку.
