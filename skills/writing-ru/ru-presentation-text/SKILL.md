# Текст презентации

Слова на слайдах, тезисы по слайдам для быстрой навигации докладчика, заметки докладчика, сопроводительный текст к презентации. Вёрстка, дизайн и сборка файла — задача навыков презентаций окружения; этот отвечает за то, что написано. Сначала загрузи `russian-text-craft`.

## Когда применять

- Подготовить или переписать текст слайдов; «сделай тезисы в отдельном файле, чтобы я быстро ориентировался, что на каком слайде»; заметки докладчика; проверить согласованность текста слайдов и доклада.
- Не применять: речь целиком (`ru-speech-and-scenario`), текст к слайдам для чтения преподавателем (`ru-teaching-materials`), отчёт в виде документа (`ru-analytical-note`).

## Слайд

- **Заголовок — утверждение, а не тема.** Не «Результаты опроса», а «Две трети студентов пользуются ИИ без разрешения преподавателя». Слушатель, прочитавший только заголовки, понимает доклад.
- Одна мысль на слайд. Если мыслей две — два слайда.
- Тело — три-пять коротких строк или одна схема, таблица, цифра. Не абзац, который докладчик будет читать вслух.
- Строка — фраза без точки в конце, до ~8–10 слов; строки параллельны по форме (все начинаются с глагола или все — с существительного).
- Цифра — крупно и с подписью, что она означает; источник — мелко внизу слайда.
- Термины совпадают с докладом и с соседними слайдами.
- Без «Введение», «Заключение», «Спасибо за внимание» как самостоятельного содержания: последний слайд — главный вывод или следующий шаг, контакты — если нужны.

## Тезисы по слайдам (шпаргалка)

Для каждого слайда: номер и заголовок → главная мысль одной фразой → две-три опоры (пример, цифра, история) → переход к следующему слайду → ответ на вероятный вопрос, если он есть. Читается одним взглядом; не дублирует текст слайда, а дополняет его.

## Заметки докладчика

Что сказать сверх слайда, в устном регистре: короткие предложения, без чтения строк слайда. Пометки действий в квадратных скобках: [пауза], [показать демо], [вопрос залу].

## Процедура

1. Главная мысль доклада и список слайдов-утверждений: прочитай только заголовки подряд — получился связный рассказ? Готово: да.
2. Тело каждого слайда — одна мысль, три-пять строк или один визуальный объект. Готово: нет абзацев на слайдах.
3. Цифры и факты с источниками. Готово: у каждой цифры источник.
4. Шпаргалка и заметки — по запросу. Готово: формат соблюдён.
5. Самопроверка по ядру (`--genre speech` для заметок, `general` для текста слайдов) и жанровая: заголовки-утверждения, параллельные строки, термины согласованы с докладом. Готово: чеклист пройден.
6. После любой правки текста — пересборка и проверка вёрстки средствами навыка презентаций: текст не вылезает за блоки, ничего не перекрывается. Готово: проверка вёрстки выполнена после последней правки.

## Нейроследы жанра

- Заголовки-рубрики: «Актуальность», «Проблематика», «Основные выводы».
- Три пункта с жирными словами и двоеточием на каждом слайде.
- Абзацы текста, которые докладчик читает вслух, повернувшись к экрану.
- «Ключевые преимущества», «новые возможности», «инновационный подход» без конкретики.
- Эмодзи как маркеры пунктов.

## Ловушки

- Красивое превью не доказывает, что текст помещается в редактируемом файле: проверка вёрстки обязательна.
- Сокращать текст слайда можно, менять факт — нет; урезанная оговорка («может» → «будет») — искажение.
- Когда слайды и документ собираются из одного исходного текста, правки вносятся туда, а не в готовый файл.

## Проверка результата

Готово, когда: заголовки подряд дают связный рассказ; на каждом слайде одна мысль; цифры с источниками; термины совпадают с докладом; шпаргалка и заметки соответствуют запросу; вёрстка проверена после последней правки текста.
