# Обработка расшифровки

Превращение сырой расшифровки (аудио, видео, интервью, совещания, фокус-группы, голосового сообщения) в читаемый документ нужного уровня: чистовую стенограмму, сплошной отредактированный текст, литературную обработку, тезисы, протокол решений. Само распознавание речи — задача навыка транскрипции окружения; этот навык начинается с готового текста. Сначала загрузи `russian-text-craft`.

## Когда применять

- «Преврати в хороший транскрипт», «отредактированный текст сплошной, чётко по транскрипту», «сделай стенограмму», «выдели решения и поручения», «тезисы по записи».
- Не применять: дословное распознавание (навык транскрипции), анализ интервью как данных исследования (методологические навыки), письмо по итогам (`ru-business-correspondence`).

## Уровни обработки

| Уровень | Что делается | Что сохраняется |
|---|---|---|
| Дословный | Только разметка: говорящие, таймкоды, [неразборчиво] | Всё, включая паразиты, повторы, оговорки |
| Чистовой | Убраны паразиты, повторы, фальстарты, оговорки, исправленные самим говорящим; расставлена пунктуация, разбиты абзацы | Порядок, смысл, слова и интонация говорящего |
| Сплошной отредактированный | Чистовой без реплик интервьюера, если просили, связный текст от лица говорящего | Только сказанное; ничего не добавлено |
| Литературная обработка | Перестройка фраз и порядка для чтения | Смысл и позиция; требует согласия говорящего на публикацию |
| Тезисы | Главные мысли по порядку, с таймкодами | Формулировки близко к сказанному |
| Протокол | Решения, поручения (кто, что, срок), открытые вопросы | Только то, что действительно решено |

«Чётко по транскрипту» значит: ничего не добавлять, не дописывать мысль за говорящего и не «улучшать» факты.

## Правила

- Не добавлять содержания: ни пояснений, ни связок, которые меняют смысл, ни выводов.
- Неразборчивое — `[неразборчиво 00:12:31]`, спорное слово — `[слово?]`. Не угадывать.
- Говорящие: по именам, если они названы в записи или у автора; иначе «Спикер 1», «Спикер 2». Не приписывать реплику по догадке.
- Имена, названия, цифры и термины сверять с контекстом и материалами; сомнительные — помечать.
- Таймкоды — по запросу или для протокола и тезисов, чтобы можно было вернуться к записи.
- Обсценную лексику и личные данные третьих лиц — по указанию автора: сохранить, смягчить с пометкой или исключить.
- Конфиденциальность: расшифровки совещаний и интервью не уходят за пределы задачи.

## Процедура

1. Уровень обработки и формат сдачи. Неясно — по умолчанию чистовой, и скажи об этом. Готово: уровень назван.
2. Прочитай расшифровку целиком; выпиши говорящих, имена, термины, цифры, сомнительные места. Готово: список.
3. Обработай по правилам уровня. Готово: весь текст.
4. Сверка: список ключевых фактов и мыслей исходника против результата — ничего не потеряно и не добавлено. Для протокола — каждое «решено» подтверждено фразой из записи. Готово: расхождений нет или они перечислены.
5. Самопроверка по ядру: для чистового и сплошного текста ритм остаётся ритмом говорящего — не выравнивай его под письменную речь; служебных реплик и плейсхолдеров нет, кроме осознанных пометок [неразборчиво].
6. Оформи (обычно Word), открой файл после записи; сообщи уровень обработки, число неразборчивых мест и что требует проверки автором.

## Ловушки

- Чистовой текст — не пересказ. Если фраза стала гладкой, но говорящий так не сказал бы, ты ушёл в литературную обработку.
- Сокращение («сократи») — отдельный запрос: по умолчанию расшифровка полная.
- Протокол без атрибуции говорящих — требование формы; спорные цифры и даты уходят в открытые вопросы.

## Проверка результата

Готово, когда: уровень назван и соблюдён; ничего не добавлено и не потеряно (проверено сверкой); говорящие и неразборчивые места размечены честно; файл открыт после записи; автору названы места для проверки.
