# Грантовая заявка и научно-проектный текст

Разделы заявок в научные фонды и университетские конкурсы, программы НИР, концепции проектов, обоснования тем, ожидаемые результаты. Отличие от статьи: эксперт должен поверить, что проект нужен, выполним этими людьми в этот срок и даст проверяемый результат. Сначала загрузи `russian-text-craft`; сравнение с существующими решениями проверяй по источникам.

## Когда применять

- Написать или переработать разделы: проблема, актуальность, новизна, цели и задачи, подход и методы, план работ, ожидаемые результаты, задел коллектива.
- Свести черновики разных авторов в одну связную заявку.
- Проверить заявку на связность, достижимость и соответствие требованиям конкурса.
- Не применять: статья по результатам (`ru-academic-article`), отчёт по гранту по форме фонда (`ru-official-documents`), рецензия на чужую заявку (`ru-review-and-feedback`).

## Что выяснить до письма

1. Конкурс и форма: название, разделы, лимит каждого раздела и его мера (обычно знаки с пробелами), критерии экспертизы, срок. Эксперт читает по критериям — текст строится по ним.
2. Какие черновики есть, какой новее, кто автор какого раздела. Расхождения (название проекта, аббревиатуры, нумерация) выпиши списком до правки.
3. Задел: публикации, прототипы, данные коллектива по теме. Без задела новизна не убеждает.
4. Что обещается: статья, прототип, методика, база данных, рекомендации — у каждого измеримая форма.
Готово, когда есть требования, карта черновиков и список обещаемых результатов.

## Сквозная логика

**Проблема** (что не работает или неизвестно, с доказательством) → **почему решать сейчас** (кому и чем мешает) → **что сделано другими и чего не хватает** (сравнение) → **наш подход** (что делаем иначе) → **задачи** (шаги с результатом) → **методы** (как решаем каждую) → **результаты** (форма и способ проверки) → **коллектив и задел** → **план и ресурсы**.

Каждая задача выводится из проблемы, каждый метод привязан к задаче, каждый результат — к задаче. Задача без результата, результат без задачи и метод без задачи — первое, что заметит эксперт.

## Язык заявки

- Конкретность вместо масштаба: «разработать методику оценки X для Y на выборке Z», а не «комплексный подход к проблеме X».
- Новизна доказывается сравнением: «в отличие от [работа 1], где …, и [работа 2], где …, мы …». «Не имеет аналогов» и «впервые в мировой практике» без сравнительного обзора — риск.
- Достижимость важнее амбиции. Амбициозный замысел делится на этап с гарантированным результатом и этап с названным исследовательским риском.
- Один словарь на всю заявку: название, аббревиатуры, компоненты и этапы совпадают во всех разделах. Составь глоссарий в рабочем файле.
- Нормативные ссылки (указы, стратегии, стандарты) — с проверенными реквизитами и актуальной редакцией.
- Канцелярит — в той дозе, которой требует форма. Глаголы действия: «измерим», «соберём», «сравним», «опубликуем».

## Нейроследы жанра

- «Актуальность темы обусловлена» + абзац общих слов о цифровизации.
- Новизна как набор прилагательных: «инновационный», «уникальный», «комплексный», «междисциплинарный».
- Задачи без объекта и результата: «изучить», «проанализировать», «разработать».
- Результаты как пожелания: «повышение качества», «формирование компетенций».
- Несколько равноправных направлений без приоритета.
- Разнобой терминов и опечатки между разделами — признак сборки из кусков.

## Процедура

1. Прочитай черновики целиком; таблица «файл → разделы → версия → расхождения». Готово: расхождения перечислены.
2. Выпиши требования и критерии; построй скелет с лимитами. Готово: скелет.
3. Сформулируй проблему, главный результат и главное отличие от существующих решений — по предложению. Готово: три спорных предложения без штампов.
4. Проверь сравнительную часть по источникам. Готово: у каждого «в отличие от» есть ссылка.
5. Напиши разделы и заполни таблицу «задача → метод → результат». Готово: пустых клеток нет.
6. Унифицируй словарь, проверь реквизиты, исправь опечатки, посчитай объём каждого раздела той мерой, что требует форма. Готово: все разделы в лимите.
7. Самопроверка по ядру (`--genre academic`) и жанровая: достижимость каждого результата, нет голословной новизны. Готово: чеклист пройден.
8. Оформи по форме фонда; передай автору список решений, которые остаются за ним: приоритет направлений, состав коллектива, биографии, сроки.

## Ловушки

- Приоритет направлений выбирает автор: предложи варианты и последствия каждого.
- Сведения о членах коллектива — только из проверяемых источников или от автора и с согласия этих людей; регалии не дописываются.
- Пометки вроде «дальше не правил» — сигнал незавершённого раздела, а не текст для переноса.
- Таблицы бенчмарков, стандартов и инструментов из черновиков проверяй построчно.
- Не подавай заявку и не заполняй личный кабинет фонда без прямого поручения.

## Проверка результата

Готово, когда: разделы соответствуют форме и лимитам; цепочка «проблема → задачи → методы → результаты» замкнута; новизна подкреплена сравнением со ссылками; словарь единый; скрипт прогнан; автору передан список решений.
