# Рецензия, заключение, замечания

Критический разбор чужой работы: статьи, концепции исследования, анкеты, студенческой работы, методики, черновика коллеги, заявки. Результат — текст, который автор работы сможет применить: где проблема, почему это проблема, как исправить. Сначала загрузи `russian-text-craft`. Специальные навыки проверки (источников, заявок, анкет), если они есть в окружении, отвечают за метод; этот — за текст рецензии.

## Когда применять

- «Разбери статью», «критически оцени», «дай замечания», «рецензия», «проверь анкету», «оцени студенческие работы по критериям», «что здесь не так».
- Подготовить примечания в документе и сопроводительное заключение.
- Не применять: оценка проекта или продукта для решения (`ru-analytical-note`), правка текста без рецензии (режимы правки ядра).

## Что выяснить до письма

1. Адресат: автор (исправит), редакция (решит), пользователь (ответит автору), преподаватель (выставит оценку).
2. Критерии: требования журнала, балльная шкала курса, требования методики. Есть — рецензия строится по ним.
3. Граница вмешательства: только замечания или ещё правка явных технических ошибок. По умолчанию чужой текст не переписывается; содержательные предложения — в примечаниях.
4. Доступ к материалу целиком: все листы, скрытые условия показа, макросы, приложения, видео. Рецензия по части материала так и называется.
Готово, когда известны адресат, критерии и граница вмешательства.

## Структура рецензии

1. **Что рецензируется.** Название, авторы, версия или дата, объём; что прочитано полностью, что нет.
2. **Общая оценка** в двух-трёх предложениях: главный вывод и главная причина. Не «работа интересная, но», а «практическая часть сильнее диагностики: опыт описан, данных об эффективности нет».
3. **Замечания по убыванию важности.** Каждое: где (страница, раздел, вопрос, слайд) → что (цитата) → почему проблема (какое правило или факт нарушено, к чему приведёт) → что сделать. Мелкие — списком в конце или в примечаниях.
4. **Что сделано хорошо** — конкретно, с локаторами: автору нужно знать, что сохранить.
5. **Решение** в форме, которой ждёт адресат: принять, доработать, отклонить; балл по критериям с обоснованием; «отправлять респондентам рано, потому что…».
6. **Границы рецензии.** Что не проверялось и почему.

**Оценка нескольких студенческих работ**: одинаковая структура для каждой; балл по каждому критерию с одной-двумя фразами обоснования и локатором; общий балл, сумма проверена. Стилистические совпадения не подтверждают ИИ-генерацию. Академическую честность оценивают по правилам учреждения и проверяемым свидетельствам, не по checker.

## Язык рецензии

- Точность важнее мягкости, уважение важнее резкости. Критикуется текст: «в разделе нет данных», а не «автор не потрудился».
- Замечание проверяемо: «утверждение о деградации на с. 1–2 не подкреплено ни динамикой показателей, ни определением термина», а не «недостаточно обосновано».
- Уровни не смешиваются: ошибка факта, логический скачок, методологический пробел, неясная формулировка, оформление.
- Предложение по исправлению — конкретное действие, а не «переработать».
- Пример лучшей формулировки — одно предложение с пометкой «например», не переписанный раздел.

## Нейроследы жанра

- «Работа актуальна и представляет интерес, однако…».
- Замечания без локаторов: «местами», «в ряде случаев».
- Дежурная похвала вокруг критики.
- «Рекомендуется доработать», «следует уточнить» без указания как.
- Вывод, который не следует из замечаний.

## Процедура

1. Получи материал целиком; список компонентов «прочитано / недоступно». Готово: список есть.
2. Прочитай всё, ведя журнал замечаний с локаторами и цитатами; оценку — после чтения. Готово: журнал.
3. Проверь ключевые утверждения рецензируемого текста по источникам, где это возможно. Готово: пометки «подтверждено / не подтверждено / не проверялось».
4. Рассортируй замечания по важности и типу; неподтвердившиеся отбрось. Готово: существенные отделены от мелких.
5. Общая оценка следует из существенных замечаний. Готово: оценка и замечания согласованы.
6. Напиши рецензию; примечания в документ — без изменения авторского текста сверх договорённости. Готово: оригинал не изменён.
7. Самопроверка по ядру и жанровая: у каждого замечания локатор и предложение, границы названы. Готово: чеклист пройден.
8. Сдай заключение и документ с примечаниями; проверь, что примечания видны; назови границы проверки.

## Ловушки

- Проверка файла в одной программе не доказывает поведение макросов в другой — так и пиши.
- Не смягчай вывод, чтобы не огорчить, и не ужесточай ради строгости: оценка привязана к критерию.
- Решение по академической честности принимает преподаватель или редакция, не рецензент-агент.

## Проверка результата

Готово, когда: названо, что прочитано; у каждого существенного замечания есть локатор, цитата, причина и предложение; оценка следует из замечаний; границы названы; авторский текст не изменён сверх договорённости; файл с примечаниями открыт; скрипт прогнан по заключению.
